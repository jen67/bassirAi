## 📌 About The Project

**BassirAI** is a multi-tenant, AI-driven patient communication platform built specifically for aesthetic clinics. It addresses the challenge of managing inbound inquiries across multiple social channels by deploying customized, bilingual (Arabic & English) AI agents capable of answering patient queries and driving automated appointment bookings[cite: 1].

### 🌟 Key Capabilities
* **Custom AI Agent per Clinic:** Dynamic prompt generation built from each clinic’s catalog, FAQs, and brand tone powered by Groq API (Llama 3.3 70B) for sub-second responses[cite: 1].
* **Unified Inbox:** Real-time messaging aggregator covering WhatsApp, Instagram, and Facebook with AI/Human takeover toggles[cite: 1].
* **Multi-Tenant Security:** PostgreSQL Row Level Security (RLS) ensuring total data isolation between clinics[cite: 1].
* **Automated Scheduling:** Dual-strategy booking system using Cal.com integration or AI-assisted qualification & handoff[cite: 1].
* **Zero-Cost Technical Stack:** Next.js 14, Supabase, n8n, Railway, and Docker[cite: 1].
